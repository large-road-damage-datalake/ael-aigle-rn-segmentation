# AEL - AIGLE_RN

## Overview

This package contains the AIGLE_RN subset from AEL as a segmentation benchmark.

- Task: segmentation
- Images: 38
- Annotations: 210
- Classes: 1 (crack)
- Annotation format: paired PNG masks

- Family: AEL Crack Detection Database
